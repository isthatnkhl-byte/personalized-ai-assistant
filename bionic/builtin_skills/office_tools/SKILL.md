# Office Tools Skill

Enables the agent to compose structured emails, resolve contact relationships, and read or inspect active clipboard data.

### Operation: `compose_email`
**Description**: Drafts a concise, professional email tailored to a recipient with the user's signature.

### Operation: `resolve_contact`
**Description**: Looks up contact details, aliases, and role context from the relationship graph.

### Operation: `read_clipboard`
**Description**: Reads text content currently stored in the Windows clipboard.
