# Web Research Skill

Empowers the agent to query Google/web search engines, extract live repository metadata from GitHub, retrieve web page text, and autonomously navigate to online services and domains.

### Operation: `tinyfish_search`
**Description**: Queries the TinyFish search engine for real-time web results with ranked titles, URLs, snippets, and domains.

### Operation: `tinyfish_fetch`
**Description**: Fetches clean markdown page content from a specified URL using TinyFish Web Agent.

### Operation: `search_github`
**Description**: Queries GitHub REST API in real-time for repositories, descriptions, star ratings, languages, and direct URLs.

### Operation: `fetch_web_data`
**Description**: Fetches live readable text and content from any safe external URL for agentic grounding.

### Operation: `search_web`
**Description**: Searches Google for information, queries, or topics.

### Operation: `open_url`
**Description**: Navigates to a specific website, web app, or URL in the default browser.
