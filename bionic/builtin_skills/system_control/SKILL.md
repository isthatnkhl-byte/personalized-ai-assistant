# System Control Skill

Enables the agent to control desktop audio playback on Spotify, launch installed Windows programs, and navigate desktop UI.

### Operation: `play_music`
**Description**: Plays a song, artist, album, or playlist on Spotify via Windows native URI protocol.

### Operation: `launch_app`
**Description**: Launches a native desktop executable or opens an installed application.
